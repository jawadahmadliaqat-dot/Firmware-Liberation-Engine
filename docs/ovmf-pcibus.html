What was recovered

PCI config cycles (CF8/CFC) attributed from Pci.Read/Write protocol calls, plus 50 visible protocol-call edges. The driver enumerates PCI devices through protocol interfaces, so its hardware reach appears as protocol provenance, not fixed MMIO. Caveat, stated plainly: protocol-attributed port entries record the engine's generic size (4); the Width argument is not decoded, so a 1-byte config phase is recorded as size 4.

Provenance

Source: Ubuntu package ovmf-generic 2025.11-3ubuntu7.3, EDK2 2025.11. PE image, 80 functions. No BAR-relative findings: BAR bases arrive at runtime as hardware inputs.

This is a static proof tool. It does not execute firmware and does not claim to find all vulnerabilities. PASS does not mean firmware is secure.
