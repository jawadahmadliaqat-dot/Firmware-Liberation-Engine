What was recovered

PCI config cycles: the generic helper's input at 000016d6 resolves per site to CF8 and CFC (two findings at one instruction, one per call-site value), plus the pre-existing CF8 output at 0000174a. This resolution needed two analyses together: per-site binding supplied the two values, and callee clobber refinement preserved the port argument across the intervening call (v3.12). Fixed-band MMIO is 0 because the driver's config addresses are parameter-computed and its BAR bases arrive at runtime.

Provenance

Source: Ubuntu package ovmf-generic 2025.11-3ubuntu7.3, EDK2 2025.11. PE image, 13 functions. No BAR-relative findings: BAR bases arrive at runtime as hardware inputs.

This is a static proof tool. It does not execute firmware and does not claim to find all vulnerabilities. PASS does not mean firmware is secure.
