Why it fails

Lean generic mode checks every port against an architectural allowlist keyed by the report's language (x86-64). Port 0x1234 is in no architectural range: not PCI config 0xCF8–0xCFF, not legacy PIC/PIT/DMA/keyboard/CMOS, not COM1–COM4. Port 0x1234 was previously proven only as a synthetic negative on a hand-built report; here it comes from BUILT firmware through the real pipeline (analyzed only, never executed). Control build (same firmware, port replaced with 0x3F8, COM1, inside the allowlist): Lean generic PASS, confinement true. The FAIL is therefore attributable to the out-of-allowlist port alone.
