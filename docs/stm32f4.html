Ground truth

150/150 code-true at v3.12, 0 unexplained extras. At v3.13 the -O0 build recovers the GPIO plane too (+21: HAL_GPIO_Init pairs for GPIOA/GPIOD, ReadPin IDR, TogglePin ODR/BSRR, WritePin BSRR), so -O0 is now 171 and the -O2 build is 171 as well. Per-peripheral (-O0, v3.13): RCC 116, on-chip memory-interface 12, PWR 7, EXTI 8 (interrupt-mode branch only), RCC bit-band aliases 7, GPIOA 9, GPIOD 12.

Named misses, stated plainly. (1) GPIO data plane at -O0: parameters spilled to stack slots defeat the must-transfer; recovered in v3.13 by stack-slot tracking (and at -O2 already). (2) USART2 data plane at BOTH builds: the HAL handle-struct pattern (handle instance stored to RAM in main, loaded back in every UART function) defeats global seeding. Generic PASS means only that what was found stayed in-window.
