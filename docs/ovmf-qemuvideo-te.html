What was recovered

Full PE parity: 13 functions, the same 3 port findings (CF8/CFC input per site plus CF8 output), the same 4 protocol edges, the same 2 unresolved calls — access sets identical to the PE twin. The only difference is the entry function's name (loader-assigned vs PE's own name). The TE loader parses the TE header per the UEFI PI spec, maps sections exactly from file bytes, and applies no relocations.

Provenance

Source: Ubuntu package ovmf-generic 2025.11-3ubuntu7.3, EDK2 2025.11. TE image. No BAR-relative findings: BAR bases arrive at runtime as hardware inputs.

This is a static proof tool. It does not execute firmware and does not claim to find all vulnerabilities. PASS does not mean firmware is secure.
