What was recovered

Generic I/O helpers with a port argument, resolved per site: serial-port block accesses (COM1 range 0x3f8–0x3fd, classic 16550 init values) and PCI config cycles (CF8/CFC), plus one legacy input at 0xCFE and one GHCB MSR read (0xC0010130). Fixed-band MMIO is 0 because this driver's hardware access flows through protocols, parameter-carried port helpers, and runtime-discovered BAR bases — not fixed addresses.

Provenance

Source: Ubuntu package ovmf-generic 2025.11-3ubuntu7.3, EDK2 2025.11 DXE driver set (6 drivers, 411 functions; DxeCore alone is 254 functions). PE image. No BAR-relative findings: BAR bases arrive at runtime as hardware inputs.

This is a static proof tool. It does not execute firmware and does not claim to find all vulnerabilities. PASS does not mean firmware is secure.
