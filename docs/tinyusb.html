Ground truth

224/224 code-true, 0 unexplained extras. Matches: clock tree (~110: crystal oscillator, both PLLs, clocks), USB device-controller control plane (~60: init, interrupt, transfer, abort, buffer control, enumeration fix, timer/alarm), GPIO config (pins 0/1/25), BOOTSEL button 4 (live, via board button read), system info 1. All 83 suspects verified programmatically as atomic-alias pages (known base + 0x1000/0x2000/0x3000) — the same profile-completeness gap as the RP2040 pilot.

Named misses, stated plainly. (1) SIO GPIO data on a live path: the LED blink writes through SIO at 0xd0000000, outside the ARM extractor window. (2) DPRAM payload bytes: transmit/receive copies go through a struct-held computed DPRAM pointer; only 4 fixed endpoint-control DPRAM registers were recovered. (3) Standing blind spot: second-stage boot code unrecovered as a function, 0 findings in its ranges. Generic PASS means only that what was found stayed in-window.
