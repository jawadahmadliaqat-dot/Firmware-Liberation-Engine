Ground truth

198/198 findings code-true against pico-sdk source (195 named SVD registers plus 3 clock-peripheral divider-slot writes that are real SDK writes but unnamed in the SVD). The 62 classifier suspects are RP2040 atomic-alias writes (CLR +0x1000, SET +0x2000, XOR +0x3000) — a profile-completeness gap, not extractor error. 15 findings are dead-linked but code-true: the engine reports what code can touch, not only what runs.

Named blind spots, stated plainly (v3.12 state; partially recovered since). (1) Boot stage 2: 34 MMIO instructions (PADS_QSPI + SSI) were never recovered, because Ghidra never recovered the second-stage boot code as a function. (2) SIO spinlocks: 32 stores at 0xd0000100–0xd0000180 were missed, because the ARM extractor window (0x40000000–0x60000000) excludes SIO at 0xd0000000. v3.19 recovered part of both (SIO +9, boot2 +13; total 198 → 220), v3.20 added the PPB band (220 → 236), and v3.24 takes the total 236 → 268; the remainder of those ranges is still open. Generic PASS means only that what was found stayed in-window.
