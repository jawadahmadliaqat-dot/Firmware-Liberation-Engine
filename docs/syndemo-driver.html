Why it fails

Lean bmp mode assigns a driver family by function-name prefix. A name starting with rcc_ belongs to the rcc family, whose only allowed range is 0x40021000–0x40021400 (the STM32F1 RCC block). The synthetic function rcc_syndemo_touch loads and stores GPIOA output data at 0x4001080c — outside that range. Only driver confinement fails; the other two fixed entries (function main, 0x40021000) match no family prefix and are unconstrained. Control build (same firmware, address replaced with in-family 0x40021004): Lean bmp PASS, driver confinement true. The FAIL is therefore attributable to the out-of-family address alone.

Display gap, not a proof gap. Lean bmp prints only the boolean driver-confinement line, not the violating entry's name. The entry above is identified from the report JSON. The FAIL is decided by the confinement check alone.
