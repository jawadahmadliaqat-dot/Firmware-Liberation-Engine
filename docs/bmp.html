Ground truth

Source cross-check against the public BMP v2.0.0 source and libopencm3: at the v3.6 stage, field truth was 116/116 (100%). Later additions were spot-checked against source, including libopencm3 parameter helpers (for example DMA channel-5 registers via dma_channel_reset) and the ADC1_CR2 read in adc_is_calibrating added by callee clobber refinement in v3.12. No finding has been lost across versions; counts moved 235 → 346 → 422 → 423 as analyses improved.

Provenance

Binary: official Black Magic Probe v2.0.0 release ELF (1,230,888 bytes, MD5 fa07d791edffdaec79be3c92d5d8373a). ARM Cortex-M, not stripped, with debug info. Profiles: hand-written STM32F1 profile, reproduced by the CMSIS-SVD importer (53 blocks). Source: public BMP repository (v2.0.0) and libopencm3.

Known limits. Stripped builds of this binary must use generic mode only: bmp mode passes vacuously on stripped input (function names are lost) and proves nothing. The engine reports what code can touch, not only what runs.
This is a static proof tool. It does not execute firmware and does not claim to find all vulnerabilities. PASS does not mean firmware is secure.
